# 02 — nc=1 基线训练 Spec

## 1. 目标

建立可复现、可比较、没有额外极小目标特殊结构的单类别羽毛球基线检测器。

```text
ASSET_READY
→ nc=1
→ 通用预训练权重初始化
→ baseline training
→ BASELINE_TRAINED
```

## 2. 类别定义

最终检测任务：

```yaml
nc: 1
names:
  0: shuttlecock
```

不以 COCO 80 类作为最终任务定义。

## 3. 基线结构

使用当前标准单帧检测结构作为基线。

允许当前工程先使用 YOLO26s 等标准结构，但本 Spec 不永久绑定具体型号。

基线阶段禁止默认加入：

- P2 专用检测分支；
- 多帧特征融合；
- 两阶段检测；
- 其他专门为极小目标增加的结构。

## 4. 初始化

正式基线从通用预训练权重开始微调。

随机初始化只允许作为诊断对照：

```text
怀疑通用预训练先验限制当前任务
→ 增加 scratch 对照
→ 不能默认取代预训练基线
```

## 5. 训练阶段

### 5.1 阶段 A：Synthetic-only

目的：

```text
三维生成数据
→ 学习基础形状、尺寸和姿态
→ 测清纯合成数据能够提供的能力
```

输出：

`BASELINE_SYNTHETIC_ONLY`

### 5.2 阶段 B：Synthetic + Real

```text
合成数据
+ 真实图片
+ 真实视频训练帧
→ 显式控制采样比例
→ 训练
```

输出：

`BASELINE_SYNTHETIC_REAL`

### 5.3 必要时阶段 C：Real-heavy

只在真实数据性能仍明显低于受控合成数据，且证据指向真实域差异时进入。

## 6. 正负样本

训练必须包含：

- 羽毛球正样本；
- 普通无羽毛球负样本；
- 后续由实际误检产生的困难负样本。

## 7. 训练记录

每次训练必须记录：

- 模型结构；
- 初始化权重；
- 数据版本；
- 合成 / 真实采样比例；
- 输入分辨率；
- batch size；
- 优化器；
- 学习率；
- epoch；
- 数据增强；
- 随机种子；
- 代码 commit；
- GPU；
- 训练耗时；
- 显存峰值；
- best weight；
- last weight。

## 8. 基线训练通过条件

本 Spec 不要求模型已经满足最终机器人需求。

只要求：

```text
训练流程正常完成
+ 配置可复现
+ 无明显数据或数值异常
+ 产生正式可测试权重
```

## 9. 退出状态

`BASELINE_TRAINED`
