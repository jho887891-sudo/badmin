## 2. 结论（只写数据支持的部分）

1. **摩擦单因素是弱依赖**：0.2→0.8→1.4 时 ΔY 从 1.21026 → 1.21544 → 1.21579 m（总变化 **0.46 %**），
   有效滚动半径 0.101030 → 0.101459 → 0.101486 m（**0.45 %**）。
   趋势与"低摩擦→更多打滑→更小有效半径/更短行程"一致，但幅度很小。
   **因此本矩阵不能证明"摩擦无关"，只能说在 0.2–1.4 之间、20 kg/4 rad·s⁻¹ 工况下摩擦不是主要限制项。**
2. **载荷单因素几乎无影响**：0 → +10 kg（20→30 kg，总重 +50 %）时 ΔY 1.21544 → 1.21478 m（**−0.05 %**），
   r_eff 0.101459 → 0.101479（+0.02 %）。这是**代理敏感性趋势**；
   **不得**与 G7B 真实臂 26.0085 kg 场景对比成同一结论（配置不同）。倾覆未发生（yaw 1.0e-04 rad）。
3. **轮速单因素**：1 vs 4 rad/s 时 ΔY **0.30399 vs 1.21544 m（比例 1:3.999，即里程与转速成正比）**，
   r_eff 0.101611 vs 0.101459（**0.15 %**）→ 速度依赖性存在但极小。
4. **有效滚动半径是真实测量值**：`r_eff = |Δ底盘Y| / |Δ关节角实测(rad)|`，8 组共 16 个 run 落在
   **0.101030–0.101611 m**，比 P1 v2 几何值 0.103 m 小 **1.35 %–1.99 %**（绝对 −1.4 ~ −2.0 mm）。
   这是**有效（含打滑）半径**，不是轮胎几何半径，也不是厂家受载半径。
5. **正负控制**：无驱动 → 位移 0.3 mm（1 mm 门禁内，PASS）；反向指令 → **+1.21636 m** 正向位移（符号正确）。
   两条控制都证明"位移是由轮驱动与接触产生的"，而不是脚本写 root。
6. **确定性**：每一组的两个 run 数值**逐位一致**（含 6 位小数的 r_eff）。

## 3. P4-02 代理质量/惯量合同（`p4_02_mass_inertia_audit.py`，exit 0）

| 检查 | 基准配置 | +10 kg 载荷配置 |
|---|---|---|

| 轮惯量与**解析圆柱**对照 | I_axis 实测 0.0053045 vs 解析 `½mr²`=0.0053045；I_trans 0.0028491 vs `m(3r²+h²)/12`=0.0028491 → 相对误差 **< 1e-4** | 同 |
| 单位 | kg / kg·m² / m 量级检查通过 | 同 |

**这是我在本项目里第一次得到"PhysX 运行时的轮惯量与解析值逐位吻合"的证据**（0.0053045 / 0.0028491），
说明轮碰撞代理（圆柱 r=0.103、半宽 0.0243）与 MassAPI 组合是自洽的；
但它只证明**代理几何的惯量自洽**，不证明真实轮胎的质量/惯量。

## 4. 明确不成立的推断

- `P4_REAL` **未通过**：0.103 m 是几何未装载半径；圆柱不是冠状踏面；摩擦 0.2/0.8/1.4 是人为档位（非厂家数据）。
- 未测试：坡道、越障、单轮悬空、温度、磨损、胎压、真实滑移率、驱动效率、电机扭矩上限。
- 载荷矩阵只到 +10 kg（30 kg）；没有做 40/50 kg 的倾覆边界。
- 速度/jerk 在根位姿未写入的前提下由物理步积分得到，但**没有**做真实的加速度/扭矩验证。
