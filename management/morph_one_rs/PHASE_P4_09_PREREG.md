# P4-09 预注册：代理速度闭环 / 停车 / 限速（TEST_PROXY）

**登记时间**：2026-10-22，**在 P4-09 GPU 运行之前**
**基线**：`p3/gate-v1.1` 的 P4_PROXY 轮关节驱动（零 root 写入）；有效滚动半径实测值来自 P4-08 矩阵
`r_eff = 0.101459 m`（16 个 run 落在 0.101030–0.101611 m）。

## 1. 控制结构（simulation-only）

- 命令：底盘沿 **−Y** 的速度 `v_cmd`（m/s），先经 `--speed-limit` 硬钳位（默认 0.50 m/s）。
- 反馈：用相邻帧底盘 Y 位移求实测速度 `v_meas`（**不用**轮速当真值）。
- 控制律：轮目标角速度 `ω_cmd = s·(v_phase + kp·(v_phase − v_meas)) / r_eff`，
  `s = ±1` 为滚动方向符号，`kp = 2.0` (1/s)，`r_eff = 0.101459 m`（**实测**有效半径）。
- 时间剖面：0–1.5 s 余弦斜坡到 `v_cmd`；1.5–4.0 s 定速保持；4.0–5.0 s 命令为零（**停车测试**）。共 600 步。

## 2. 预注册门禁（冻结）

| Gate | 判据 | 依据 |
|---|---|---|
| `all_finite` | 遥测全有限 | 健全性 |
| `no_root_pose_write` | `root_writes == 0` | 禁止伪装驱动 |
| `contact_detected` | 轮/地接触峰值 > 1.0 N | 与 G4/G6/G7 同判据 |
| `steady_speed_tracks_command` | 保持窗（1.5–4.0 s）平均速度相对误差 **≤ 0.15** | 15 % 是代理级追踪门禁，小于 P4-08 观察到的工况差异 |
| `stops_after_zero_command` | 命令归零后 0.5 s 内最大速度 **≤ 0.02 m/s** | 与 P2 静置 1 mm 同量级的速度判据 |
| `speed_limit_respected` | 全程峰值速度 **≤ 1.10·v_cmd_eff + 0.02 m/s** | 超调允许 10 %+2 cm/s |

## 3. 运行计划（GPU 串行，每组 2 个独立 RUN_ID）

| RUN_ID | v_cmd | speed-limit | 期望 |
|---|---|---|---|
| `P4V_030_rNN` | 0.30 | 0.50 | 追踪 ≤15 %，停车 ≤0.02 m/s |
| `P4V_050_rNN` | 0.50 | 0.50 | 上限边界 |
| `P4V_clamp_rNN` | **0.80** | **0.50** | 必须被钳位到 0.50，峰值 ≤0.57 且 `clamped=true` |

## 4. 明确边界

- 这是**代理**闭环：圆柱踏面、TEST_PROXY 质量/惯量、`r_eff` 来自代理实测；**不是** `P4_REAL`。
- 不做坡道、侧滑、单轮悬空、真实电机扭矩/电流限制、真实编码器噪声与延迟。
- 停车测试只证明"命令归零后轮速收敛、底盘速度降到 0.02 m/s 以下"，**不是**安全级急停（无 E-stop 硬件）。
