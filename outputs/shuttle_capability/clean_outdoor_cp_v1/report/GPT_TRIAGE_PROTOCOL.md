# COCO 候选图初审任务（交给 GPT 用）

## 1. 背景（请先读完再判图）
我们在为**羽毛球检测训练**筛选 COCO train2017 的照片，要两个池子：

- **A 池 / 背景**：真实**户外**、画面里**没有羽毛球**的干净照片。之后会把真实羽毛球抠出来"贴"到这些背景上，生成合成训练样本。
- **B 池 / 困难负样本**：真实**户外**、**没有羽毛球**，但含有**容易让检测器误报**的东西（白色栏杆/反光/羽毛状枝叶/纸片/亮广告牌/雪地/白色球场线/密集小白点）。

⚠️ **关键前提**：COCO 数据集**不标注羽毛球**。所以"COCO 里没标"**不能**作为"画面里没有球"的证据 —— 必须看像素判断。

## 2. 包里有什么
| 文件 | 内容 |
|---|---|
| `A_background_01..26.jpg` | 501 个背景候选，每张 20 格（5 列 × 4 行），已按"纹理最干净"排序 |
| `B_hardneg_01..20.jpg` | 400 个困难负样本候选，每张 20 格，已按"白色像素占比"从高到低排序（最像的先看） |
| `C_foreground_review_01.jpg` | 120 个真实羽毛球前景候选（本任务只需粗筛：能否清楚看到球本体） |
| `cells_manifest.csv` | **每格 ↔ coco_image_id 的权威对应表**（sheet / cell / coco_image_id / role / clean_roi / license） |

图上的红色方框是算法建议的"干净 ROI"，**判图时请忽略它，按整张图判断**。

## 3. 你要输出什么（只要 CSV，不要长文）
每个格一行，表头固定：

```csv
sheet,cell,coco_image_id,A_outdoor,A_no_ball,A_usable,B_outdoor,B_no_ball,B_hard,B_reason
```

- `A_outdoor`：是否真实**户外**（true / false / unknown）。室内卫生间、厨房、餐馆、卧室、商场、**室内**体育馆 → false；露天球场、海滩、街道、公园 → true。
- `A_no_ball`：画面里是否**没有**羽毛球或任何球类（true = 没有）。
- `A_usable`：`A_outdoor && A_no_ball` 的结果。
- `B_outdoor` / `B_no_ball`：同上，对 B 池判断。
- `B_hard`：是否含"白色/高反光/羽毛状/细碎高光/密集小白点/白色线条"这类易误报物（true / false / unknown）。
- `B_reason`：简短英文标签，例如 `indoor_bathroom` / `white_railing` / `feather_grass` / `signage` / `ball_present` / `no_distractor` / `unclear`。

## 4. 判定细则
1. **有球就淘汰**：能看出羽毛球（包括高速运动形成的白色模糊小球、只露出羽毛或球头）→ `no_ball=false`。
2. **室内淘汰**：卫生间、厨房、餐馆、卧室、商场、室内体育馆 → `outdoor=false`。
3. **合成图 / 图表 / 屏幕截图 / 纯色块 / 海报** → 两个池子都不要。
4. 人物、动物、车辆、建筑、食物**不影响**可用性——我们只关心"是否户外"和"有没有球"。
5. 画面太小或看不清 → 写 `unknown`，**不要猜**。
6. 不要臆测拍摄地点；不要因为"看起来像体育场"就断定是羽毛球场。

## 5. 交付方式
- 先输出 `A_background_*`（26 张）的 CSV 行。
- 再输出 `B_hardneg_*`（20 张）的 CSV 行。
- 最后一行给汇总：`A_usable = X / 501`、`B_hard = Y / 400`。

## 6. 必须知道的边界
- 这是**初筛**，不是最终验收。被接受的图之后还会由人在**全分辨率原图**上复核一遍，并确认许可证。
- 不要声称"COCO 没标注，所以没有球"——这正是本任务要人看图的原因。
- 如果某一格你无法判断，就写 `unknown`；我们宁可多复核，也不要假阳性。
