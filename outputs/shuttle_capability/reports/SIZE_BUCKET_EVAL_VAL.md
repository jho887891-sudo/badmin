## 3. 推理与判定参数

| 项 | 值 |
|---|---|
| imgsz | **1024** |
| confidence（P/R/F1 工作点） | **0.25** |
| AP 曲线的 confidence 下限 | 0.001（避免截断 PR 曲线） |
| **Primary metric** | **IoU >= 0.5**，一对一贪心匹配（按 confidence 降序，GT 与预测各自最多匹配一次） |
| **Secondary metric** | **中心距离 <= 25 px（原图像素）**，ETH 作者口径，单独成表，**不与主指标混合** |
| 尺寸口径 | **equiv_size_640** = sqrt(w_px·h_px) × (640 / max(W,H))，**不使用 1024 输入上的像素尺寸** |

## 12. 结论与后续

1. **Frozen Test 至今未被使用**，本报告与任何参数选择都只基于 val；Frozen Test 保留到 Stage B/C 全部结束、模型与训练方案冻结后再正式执行。
2. 当前 Stage B `best.pt` 是**训练中途**的检查点（约 epoch 30/70），上述 delta 只作过程观察；训练结束后必须用同一工具重跑 Stage A / Stage B-best / Stage B-last 三者的对照。
3. 真正的瓶颈仍然清楚：**4-6 px（Recall 0.35-0.37）与 <4 px（0.04）** 几乎没有能力，**16-32 px 的真实样本仅 395 个**（GT 343 + 52）→ 需要靠自采真实数据补，而不是靠改训练参数。
4. 误检仍然偏高：val 上 FP=1,168-1,269（Precision 0.685-0.688），对应「白衣/灯光/场馆杂物」类困难负样本问题，后续需要专门的困难负样本评测（`hard_negative_eval`）。
